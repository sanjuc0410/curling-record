# 컬링 기량 기록부 — 구글 시트판 설치 안내

로그인 없이 **링크 + 코치 PIN**만으로 휴대폰·태블릿에서 쓰는 버전입니다.
기록은 선생님 구글 드라이브의 구글 시트 한 곳에 모입니다. 처음 한 번만 아래 순서대로 설치하면 됩니다(약 10분).

준비물: 구글 계정 1개 (개인 Gmail 권장), 이 폴더의 `Code.gs`, `Index.html` 파일

---

## 1단계. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 에 접속해 새 스프레드시트를 만듭니다.
2. 제목을 `컬링 기량 기록부`로 바꿉니다.

## 2단계. 코드 넣기
1. 시트 상단 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 왼쪽 파일 목록의 `Code.gs` 안 내용을 모두 지우고, 이 폴더의 **`Code.gs` 내용을 통째로 붙여 넣습니다.**
3. 파일 목록 옆 **＋ → HTML** 을 눌러 파일 이름을 **`Index`** 로 만듭니다. (`.html`은 자동으로 붙습니다.)
4. 새로 생긴 `Index.html` 내용을 모두 지우고, 이 폴더의 **`Index.html` 내용을 통째로 붙여 넣습니다.**
5. 💾 **저장**(Ctrl+S)을 누릅니다.

## 3단계. 초기 설정과 PIN 정하기
1. 구글 시트 화면으로 돌아가 **새로고침(F5)** 합니다. 잠시 뒤 상단에 **`컬링 기록부`** 메뉴가 생깁니다.
2. **컬링 기록부 → ① 초기 설정 (처음 한 번)** 을 누릅니다.
   - 처음에는 "승인 필요" 창이 뜹니다. **계속 → 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용** 순서로 진행하세요. 본인이 만든 스크립트라서 나오는 정상 안내입니다.
3. **컬링 기록부 → ② 코치 PIN 설정·변경** 을 눌러 숫자 4~12자리 PIN을 정합니다. (예: 코치들에게만 알려 줄 6자리 숫자)
   - PIN은 코드가 아니라 스크립트 설정값에 따로 저장됩니다.

## 4단계. 웹앱으로 배포하기
1. Apps Script 화면 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 고릅니다.
3. 다음처럼 설정합니다.
   | 항목            | 설정값                 |
   | :---            | :---                   |
   | 설명            | 컬링 기록부 v1         |
   | 다음 사용자로 실행 | **나**               |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |
4. **배포** 를 누르면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
   - 이 주소가 코치들에게 보낼 **앱 링크**입니다.

> ⚠️ **'모든 사용자'가 목록에 없으면**: 학교·교육청 구글 계정이라 관리자가 막아 둔 경우입니다. 개인 Gmail 계정으로 1단계부터 다시 만들어 주세요.

## 5단계. 코치에게 공유하기
- 코치들에게 **웹 앱 URL**과 **PIN**을 보냅니다.
- 휴대폰에서 링크를 열고 PIN을 한 번 입력하면 그 기기에서는 계속 접속된 상태로 쓸 수 있습니다.
- 팁: 휴대폰 브라우저 메뉴의 **"홈 화면에 추가"** 를 누르면 앱처럼 바로 열 수 있습니다.

## 사용 중에 알아 둘 것

| 상황                         | 방법                                                                  |
| :---                         | :---                                                                  |
| 처음 화면을 미리 보고 싶을 때 | 앱의 **설정 → 예시 데이터 넣기** (학생A~D 가상 기록). 설정에서 일괄 삭제 가능 |
| 다른 코치 입력이 안 보일 때   | 20초마다 자동으로 받아옵니다. 급하면 **설정 → 지금 동기화**             |
| 빙상장 와이파이가 끊겼을 때   | 입력은 기기에 보관되고(상단 "연결 끊김 · 대기 n건"), 연결되면 자동 전송 |
| 엑셀처럼 결과를 보고 싶을 때  | 시트 메뉴 **컬링 기록부 → 평가결과 표 만들기** → `평가결과` 탭        |
| 코치가 그만두었을 때          | **② 코치 PIN 설정·변경** 으로 PIN을 바꾸면 모든 기기에서 새 PIN을 다시 입력 |
| 오류가 의심될 때              | 시트의 `로그` 탭에서 시간·동작·오류 내용을 확인                        |

### 시트 탭 안내
- `teams`, `players`, `sessions`, `records`, `notes`, `config` 탭은 **앱이 쓰는 원본**입니다.
  오른쪽 열(이름, 날짜 등)은 보기용이라 **시트에서 직접 고쳐도 앱에 반영되지 않습니다.** 수정은 앱에서 하세요.
- 백업: 시트 메뉴 **파일 → 사본 만들기** 또는 **다운로드 → Excel**.

### 화면 구성 (v2)
| 메뉴        | 누가       | 하는 일                                                        |
| :---        | :---       | :---                                                           |
| 오늘 평가판 | 코치       | 그날 모든 시트의 선수 × 항목 점수표가 한 화면에, 칸을 눌러 점수 입력 |
| 결과 보기   | 코치·학생  | 날짜별 시트 결과표, 이름을 누르면 회차 점수·지난번 대비 변화·기능별 막대 |
| 순위·선발   | 코치       | 반영할 평가·항목·비중을 골라 선수 순위, 상위 N명 선발 표시, 표 복사 |
| 선수 모드   | 학생       | [기록하기] 위에서 시트를 고르면 선수 이름이 가로로 나란히(태블릿 7~8명), 이름 아래 5~1 버튼을 바로 눌러 기록 / [결과 보기] |
| 기록 정리   | 코치       | 깃발 표시한 선수부터 메모·특이사항을 나중에 입력                 |
| 팀 현황·선수 분석 | 코치 | 기능별 변화, 팀 평균 비교                                       |
| 설정        | 코치       | 팀·선수·평가 항목                                               |

- **선수 모드**는 평가판의 [선수 모드] 버튼으로 켭니다. 시트마다 태블릿을 세워 두면 아이들이 이름만 눌러 기록합니다.
- 선수 모드에서 코치 화면으로 돌아갈 때는 **코치 PIN**을 입력해야 합니다.
- 아이들이 입력한 점수는 코치가 입력한 점수와 똑같이 저장·분석됩니다.

### 평가 삭제
- **결과 보기**에서 날짜를 고르고 **"날짜 평가 모두 삭제"** 를 두 번 누르면 그날 평가와 점수가 모두 지워집니다(되돌릴 수 없음).
- 시트 하나만 지우려면 그 시트의 **"이 시트 평가 삭제"** 를 두 번 누릅니다. 특이사항(부상·컨디션 등)은 지워지지 않습니다.

### GitHub에서 쓰기 (선택)
`github` 폴더와 `GitHub_올리기.md` 를 보세요. 데이터는 그대로 구글 시트에 저장되고, 화면만 GitHub 주소로 엽니다.

### 코드를 고친 뒤 다시 배포할 때
Apps Script에서 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**. 이렇게 하면 **링크가 바뀌지 않습니다.**
("새 배포"를 다시 만들면 링크가 새로 생기니 주의하세요.)
