# 컬링 기량 기록부

컬링 팀 훈련에서 선수들의 기본 기능을 시트(A~F)별로 평가·기록하고, 변화와 선발 순위를 확인하는 웹앱입니다.
휴대폰·태블릿에서 로그인 없이 **링크 + 코치 PIN**으로 사용합니다.

## 주요 기능
- **오늘 평가판**: 그날의 시트 A~F가 나란히, 선수 × 평가 항목 점수표에서 바로 입력
- **선수 모드**: 아이들이 자기 이름 아래 1~5 버튼을 눌러 직접 기록, 옆으로 밀어 시트 이동
- **결과 보기**: 날짜별 결과, 선수별 회차 점수·지난번 대비 변화·기능별 막대, 날짜/시트 단위 삭제
- **순위·선발**: 반영할 평가·항목·비중을 골라 순위, 상위 N명 선발 표시, 표 복사
- **기록 정리**: 깃발 표시한 선수의 메모·특이사항을 훈련 후 입력
- **팀 현황·선수 분석**: 8개 기본 기능(딜리버리 밸런스, 릴리즈, 라인, 샷, 스위핑, 웨이트, 하우스 콜, 전술)의 변화

## 구조
| 위치                     | 역할                                                             |
| :---                     | :---                                                             |
| `index.html`             | 화면. GitHub Pages에서 열거나 Apps Script 안에서 그대로 사용       |
| `apps-script/Code.gs`    | 서버. 구글 시트에 저장, PIN 확인 (`api`, `doPost`)               |
| `apps-script/Index.html` | Apps Script용 화면 (`index.html`과 같은 파일)                      |
| `docs/`                  | 설치 안내, 설계서                                                 |

## 보안
- 이 저장소에는 **학생 정보, PIN, 서버 주소가 들어 있지 않습니다.**
- 데이터는 관리자의 구글 시트에만 저장됩니다.
- PIN은 Apps Script의 스크립트 속성(`COACH_PIN`)에 저장됩니다.
- 서버 주소는 각 기기에서 처음 한 번 입력하거나 `?api=` 링크로 전달되며, 그 기기 브라우저에만 저장됩니다.
